# Проект конвертера валют

## Что было реализовано
- Хранилище JSON
- CRUD-операции
- Конвертация валют
- CLI-меню
- Модульные тесты (pytest)

## Подход к тестированию
Использовался TDD:
1. Тест на запись
2. Тест на сбой
3. Реализация функции
4. Пройдите тест

## Трудности
- Работа с файловым хранилищем
- Написание тестов на основе крайних случаев
- Структурирование CLI-логики

## Моделирование поддержки
Исправлены ошибки с помощью GitHub Issues и патчей (1.0.x)

## Заключение
