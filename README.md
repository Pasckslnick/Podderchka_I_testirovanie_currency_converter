# Currency Converter

Консольное приложение для конвертации валют с использованием локального JSON-хранилища.

Проект разработан в рамках мини-проекта по дисциплине **«Модули и технологии программирования»** с применением методологии **TDD (Test Driven Development)**, системы контроля версий **Git** и платформы **GitHub**.

---

# Возможности

Приложение позволяет:

* ✅ Добавлять новую валюту
* ✅ Обновлять курс валюты
* ✅ Удалять валюту
* ✅ Искать валюту
* ✅ Просматривать список всех валют
* ✅ Конвертировать валюты
* ✅ Сохранять данные между запусками программы

# Архитектура

Проект разделён на несколько модулей.

## database.py

Отвечает за работу с JSON-хранилищем.

Функции:

* load_data()
* save_data()
* add_currency()
* update_currency()
* delete_currency()
* find_currency()

---

## converter.py

Реализует бизнес-логику конвертации.

Функция:

```
convert_currency()
```

Проверяет:

* корректность суммы;
* корректность курсов;
* невозможность деления на ноль.

---

## menu.py

Реализует пользовательский интерфейс.

Поддерживает команды:

* add
* update
* delete
* convert

---

## tests/

Содержит автоматические тесты для всех основных функций проекта.

# Установка

Клонировать репозиторий

```bash
git clone https://github.com/<your_username>/CurrencyConverter.git
```

Перейти в папку проекта

```bash
cd CurrencyConverter
```

Создать виртуальное окружение

Windows

```bash
python -m venv venv
venv\Scripts\activate
```

Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

Установить зависимости

```bash
pip install -r requirements.txt
```

---

# Запуск программы

```bash
python app.py
```

# Запуск тестов

Все тесты:

# Методология разработки

Проект разрабатывался по методологии **TDD (Test Driven Development)**.

Для каждой функции использовался следующий цикл:

1. Написание теста
2. Запуск теста (ошибка)
3. Реализация функции
4. Повторный запуск теста
5. Рефакторинг

---

# Реализованные функции

### Работа с валютами

* Добавление валют
* Обновление курса
* Удаление валют
* Поиск валют
* Просмотр списка валют

### Конвертация

Поддерживается конвертация между любыми валютами, присутствующими в базе.

Используемая формула:

```
result = amount * to_rate / from_rate
```

---

# Обработка ошибок

Приложение корректно обрабатывает:

* отрицательные суммы;
* отрицательные курсы;
* нулевой курс;
* отсутствие валюты;
* повторное добавление существующей валюты;
* удаление отсутствующей валюты.

---

# Хранение данных

Все данные сохраняются в формате JSON.

Пример:

```json
{
    "USD": 1.0,
    "EUR": 0.92,
    "RUB": 78.5
}
```

После закрытия программы данные сохраняются автоматически.
